# RELEASE

Use Superpowers preferencialmente se disponível.

Antes de release, valide:

- Testes
- Build
- Docker Compose
- Pipeline GitLab CI/CD
- GitLab Runner
- Harbor
- Imagens por componente ou stack
- Migrations
- Variáveis de ambiente
- Logs
- Métricas
- Healthcheck
- Segurança
- Documentação
- Plano de rollback

Confirme também se a entrega final do projeto já possui fluxo de CI/CD pronto para uso no padrão GitLab CI, GitLab Runner e Harbor.

Gere uma checklist final para DEV, HML e PRD.

TEMPLATE ENTERPRISE PARA CODEX - V3 CLEAN

OBJETIVO
Este pacote cria uma base de governança para projetos no Codex.

Esta versão foi ajustada para reduzir redundâncias.
Agora existem fontes únicas para assuntos específicos:

- SUPERPOWERS.md: regras de uso do Superpowers
- IMPECCABLE_UI.md: regras de UX/UI Impeccable
- STACK.md: tecnologias oficiais do projeto
- UI_COMPONENTS.md: componentes reutilizáveis
- MONITORING.md: monitoramento
- OBSERVABILITY_FIRST.md: observabilidade obrigatória por funcionalidade

COMO USAR

1. Extraia este ZIP.
2. Copie todos os arquivos para a raiz do novo projeto.
3. Edite os arquivos específicos do projeto.
4. Abra o repositório no Codex.
5. Execute:

prompts/START_PROJECT.md

6. Aguarde o Codex analisar o projeto.
7. Aprove ou ajuste o plano.
8. Para criar funcionalidades, use:

prompts/CREATE_FEATURE.md

9. Para corrigir bugs, use:

prompts/FIX_BUG.md

10. Para revisão de UI, use:

prompts/IMPECCABLE_REVIEW.md

11. Para revisão usando Superpowers, use:

prompts/SUPERPOWERS_REVIEW.md

12. Para revisão de observabilidade, use:

prompts/OBSERVABILITY_REVIEW.md


ARQUIVOS QUE VOCÊ NORMALMENTE VAI ALTERAR

1. PRODUCT.md
   - Nome do projeto
   - Objetivo
   - Público-alvo
   - Problemas resolvidos
   - Módulos
   - Integrações
   - Fora do escopo

2. ROADMAP.md
   - MVP
   - Versão 1.0
   - Versão 2.0
   - Backlog futuro

3. STACK.md
   - Altere se a stack mudar.
   - Exemplo: FastAPI para NestJS, Material UI para Shadcn etc.

4. DESIGN.md
   - Ajuste se o projeto precisar de identidade visual diferente.

5. DEVOPS.md
   - Ajuste se o deploy for diferente.

FLUXO RECOMENDADO

4. Ajustar DESIGN.md se necessário
5. Rodar prompts/START_PROJECT.md
6. Aprovar plano
7. Implementar módulo com prompts/CREATE_FEATURE.md

9. Melhorar UI com prompts/IMPROVE_UI.md
